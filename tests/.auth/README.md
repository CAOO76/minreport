# Playwright Test Authentication States

This directory stores authentication states for different user roles.
These files are generated during global setup and used by fixtures.

**DO NOT COMMIT THESE FILES TO GIT**

Files:
- `super-admin.json` - Super Admin authentication state
- `enterprise-owner.json` - Enterprise Owner authentication state (future)
- `edu-student.json` - Educational Student authentication state (future)
- `worker-user.json` - Worker/Operator authentication state (future)
- `personal-user.json` - Personal User authentication state (future)
